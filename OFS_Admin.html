These are the live Discord bot pay rules from the existing currency_rules Sheet tab.

How Pay Rules Work

RuleThe fixed payout rule the bot already knows. Stat and snapshot columns stay protected here so this screen only changes safe rule settings.
Amount Per UnitHow much currency is paid for each new unit. Example: 3 Silver per completed quest means +2 quests pays 6 Silver.
Unit NotesOnly Total Quest Length uses time units: 1 unit = 1 minute. All other rules pay per tracked event, using the selected currency.
Min RoleThe lowest Discord/OFS rank allowed to earn this rule. Leave blank only if every tracked member should qualify.
EnabledTRUE means the bot can pay this rule. FALSE keeps the rule visible but stops future payouts from it.
Currency TypeThe currency paid by this rule: Gold, Silver, or Copper. Keep spelling consistent with the bot economy.
NotesPlain-language admin notes explaining the rule purpose. Notes do not change payout logic.
